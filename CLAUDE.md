# Инструкции для Claude

## После каждого изменения

После завершения любой задачи, связанной с изменением кода в проекте:

1. **Коммит** — создать git commit со всеми изменёнными файлами и описательным сообщением на русском языке
2. **Пуш** — выполнить `git push origin main` чтобы изменения попали в GitHub и задеплоились на сервер

Не накапливать изменения — коммитить и пушить сразу после каждой выполненной задачи.

## Проект

- **Стек**: Next.js 16, React 19, TypeScript, Prisma + SQLite, NextAuth v5, SWR, Tailwind CSS v4
- **Деплой**: Docker на VPS, автоматический через push в main
- **Язык интерфейса**: русский
- **Тема**: поддержка светлой/тёмной/системной через CSS-переменные
- **Тесты**: Vitest + React Testing Library (`npm test`)
- **Линтинг**: ESLint + Prettier с pre-commit хуком (husky + lint-staged)

## Команды

- `npm run dev` — локальная разработка
- `npm run build` — сборка
- `npm run lint` — линтинг
- `npm test` — тесты
